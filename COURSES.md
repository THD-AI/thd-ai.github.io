## Independent work and related projects

- [THD Room Finder](https://github.com/THD-AI/THD-Room-Finder) is an independent campus tool. No course code or semester is assigned.
- [Studybooks](https://github.com/THD-AI/studybooks) spans multiple modules. Use each book's own course information.
- [iTravel](https://github.com/arudaev/iTravel) identifies itself as a Media Technology project. It is outside the AIN-B course list; its exact module and semester are not documented in its README.
- [Smart Bin Recognition](https://github.com/arudaev/smart-bin-recognition) and [bahn-predict](https://github.com/arudaev/bahn-predict) continue ideas from Painfully Trivial. They are successor projects, not additional course submissions. [The delay-prediction paper](https://github.com/arudaev/ml-db-delay-paper) documents the earlier ML work.

## Sources and corrections

Course codes, names, and scheduled semesters were checked on 18 October 2026 against the [official AIN-B module handbook](https://www.th-deg.de/Studierende/Antraege-und-Organisatorisches/Modulhandbuecher/modulhandbuch-ain-b-ws25-26.pdf) (document dated 7 September 2026; Internet Technologies p. 33, Assistance Systems p. 51, Machine Learning p. 67, Computer Vision p. 70, Deep Learning/Big Data p. 93). The [2023 handbook](https://cs-mariakirchen.th-deg.de/Studierende/Antraege-und-Organisatorisches/Modulhandbuecher/Module%20Handbooks/modulhandbuch-ain-b-en.pdf) also identifies these modules in the original cohort curriculum.

Project associations use the creators' confirmation and repository evidence: [CheXVision README](https://github.com/arudaev/chexvision#readme), [Mini README](https://github.com/arudaev/chexvision-mini#readme), [Painfully Trivial README](https://github.com/arudaev/Painfully-Trivial#readme), and [Devablos prototype README](https://github.com/THD-AI/Devablos-Project#readme). Alexander confirmed the Assistance Systems association for Apero and both course associations for Painfully Trivial. Its README explicitly records Machine Learning; the Computer Vision association is creator-confirmed rather than a claim of a separate graded submission.

The official course name is **Internet Technologies**, not Ethernet Technologies, and **Assistance Systems**. Rasa is a framework used by Apero, not a separate module. Project names, creator credits, original artwork, licences, and repository URLs are preserved. GitHub has no separate repository display-name field, so course-first names appear in descriptions, documentation, and the showroom.

Curricula can change. When adding coursework, provide the programme, exact module code, course name, scheduled semester, handbook edition, and evidence linking the project to the course. For personal work, leave course fields empty. Never infer an academic assignment from its technical subject alone.
